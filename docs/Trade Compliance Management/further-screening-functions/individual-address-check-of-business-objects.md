To trigger a Compliance check for an existing business object you can use the following function modules:

* /AEB/CMP\_CUSTOMER\_SCR\_CHECK for a customer record
* /AEB/CMP\_MD\_SCR\_CHECK for a material document
* /AEB/CMP\_PD\_SCR\_CHECK for a purchase document
* /AEB/CMP\_VENDOR\_SCR\_CHECK for a vendor record
