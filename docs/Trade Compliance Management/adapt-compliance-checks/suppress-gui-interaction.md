If you want to suppress the message box that shows a critical compliance result after changing a business object, you can use the following BAdIs:

| Business object   | BAdI name               |
| :---------------- | :---------------------- |
| Business partner  | /AEB/CMP\_BUS\_PRT\_05  |
| Customer          | /AEB/CMP\_CUSTOMER\_04  |
| Delivery          | /AEB/CMP\_DLV\_DC\_06   |
| Sales document    | /AEB/CMP\_SALES\_DC\_06 |
| Vendor            | /AEB/CMP\_VENDOR\_04    |
| Purchase Document | /AEB/CMP\_PURCH\_DC\_01 |
