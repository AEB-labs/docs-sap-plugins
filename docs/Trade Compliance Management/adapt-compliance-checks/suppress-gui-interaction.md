If you want to suppress the message box that shows a critical compliance result after changing a business object, you can use the following BAdIs:

| Business object   | BAdI name            |
| :---------------- | :------------------- |
| Business partner  | /AEB/CMP_BUS_PRT_05  |
| Customer          | /AEB/CMP_CUSTOMER_04 |
| Delivery          | /AEB/CMP_DLV_DC_06   |
| Sales document    | /AEB/CMP_SALES_DC_06 |
| Vendor            | /AEB/CMP_VENDOR_04   |
| Purchase Document | /AEB/CMP_PURCH_DC_01 |
