To create your own log entries, use the following functions:

* /AEB/CMP\_WRITE\_CRITICAL\_LOG  
* /AEB/CMP\_WRITE\_ERROR\_LOG  
* /AEB/CMP\_WRITE\_INFO\_LOG 
* /AEB/CMP\_WRITE\_WARNING\_LOG
