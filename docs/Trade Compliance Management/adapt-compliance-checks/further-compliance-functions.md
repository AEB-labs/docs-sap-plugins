## Adapt opening of HTML controls

You can use BAdI  /AEB/CMP_AF_WIN to adapt how HTML controls (the web UI of Trade Compliance Management) are opened.

Based on the return value HTML controls will open as follows:

- EX for external browser window
- FS for full screen
- MD for a modal dialog window

The BAdI is not applicable for opening the goods list and single licence.

If the general setting for opening engine applications is set to "open in external browser", the BAdI is also not applicable.
