Maintenance and development of the AEB add-ons may at any time cause changes to the standard routines and internal programming. For this reason, customers are prohibited from programming in such a way that directly addresses internal programming functionalities (such as in the SAP® standard object code). This restriction does not extend to documented code designed to facilitate customer use ("public funtions"), such as an interface for accessing product functionalities.
